# Aswin Suresh — Model Portfolio

A responsive, static portfolio website prepared for GitHub Pages. It includes the supplied photographs, light/dark theme toggle, mobile navigation, image gallery with a keyboard-accessible lightbox, FAQ accordions and contact link.

## Files
- `index.html` — page content and sections
- `styles.css` — layout, typography, responsive styling and themes
- `script.js` — theme preference, mobile menu and gallery lightbox
- `images/` — the ten supplied photographs

## Before publishing
1. Open `index.html`.
2. Find `your-email@example.com` and replace it with the public email address you want visitors to use.
3. Optionally update the location and biography text if you want more specific details.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `aswin-model-portfolio`.
2. Upload **all contents** of this folder (not just the ZIP) to the repository root. Keep the `images` folder and its filenames unchanged.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish. Your site URL will be shown in the Pages section, usually `https://YOUR-USERNAME.github.io/aswin-model-portfolio/`.

The site is static and does not need a backend or build step. The Google Fonts import uses an internet connection; fallback fonts are included.
